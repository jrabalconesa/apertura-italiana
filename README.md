# La Italiana · Laboratorio de apertura

Aplicación local y autónoma para estudiar la Apertura Italiana a partir del material de **Mi Repertorio de Ajedrez · Cuaderno 1**.

## Versión web

La aplicación se publica automáticamente en:

https://jrabalconesa.github.io/apertura-italiana/

## Abrir la aplicación

La opción más sencilla es abrir `index.html` con un navegador moderno.

La opción recomendada en Windows es hacer doble clic en `INICIAR_APP.bat`. Se abrirá el navegador automáticamente y la aplicación quedará disponible en `http://127.0.0.1:8000`.

También puedes iniciar el servidor manualmente desde PowerShell:

```powershell
node server.cjs
```

Después visita [http://localhost:8000](http://localhost:8000).

No necesita instalar dependencias ni conectarse a ningún servicio. El progreso se guarda en el almacenamiento local del navegador.

## Contenido

- **Aprende:** recorrido guiado por las posiciones ITA-P01 a ITA-P12.
- **Practica:** reproducción de la jugada temática sobre el tablero.
- **Partidas:** visor paso a paso de las tres partidas modelo ITA-M01 a ITA-M03.

Los archivos originales DOCX, PDF, PGN y CSV se conservan junto a la aplicación como material de referencia.
